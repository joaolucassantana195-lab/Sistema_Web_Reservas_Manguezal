# Sistema_Web_Reservas_Manguezal
Sistema web completo para o gerenciamento de reservas no Restaurante Manguezal. Possui site completo para clientes enviarem os dados necessários, painel administrativo para alocação de mesas, definição de usuários, alteração de status, envios de emails e lembretes automáticos, histórico de clientes  e ajuste de configurações conforme a demanda.
